# AGENTS.md — инструкции для Codex

Проект: **Logo/Icon 3D Animator** — веб-инструмент (упрощённый аналог Blender), который превращает PNG/SVG в 3D-модель, анимирует её пресетами/таймлайном и экспортирует в Lottie (.json/.lottie) и MP4 для iOS и Android.

Полная спецификация — в `SPEC.md`. Читай её целиком перед началом работы. Это единственный источник требований.

## Как работать
- Работай этапами из раздела 9 `SPEC.md`. Один этап = одна ветка/серия коммитов. После этапа остановись и дай отчёт: что сделано, как запустить, чек-лист проверки, известные ограничения. Не переходи к следующему этапу без моего «дальше».
- Начни с Этапа 0: НЕ пиши код. Создай `docs/PLAN.md` (стек, структура папок, схема модели проекта в TypeScript-типах, список рисков, до 5 вопросов ко мне). Остановись.
- Сначала рабочий вертикальный срез, потом расширение. Не усложняй.
- Если что-то технически невозможно или даёт плохой результат — скажи прямо и предложи альтернативу, не имитируй.

## Правила кода
- Vite + TypeScript (strict, без `any`), Three.js, React + Zustand. Точные версии зависимостей фиксируй в `package.json`.
- Единая JSON-сериализуемая модель проекта — источник правды. Рендер, превью и экспорт читают только её.
- Команды: `npm run dev`, `npm run build`, `npm test`, `npm run lint` — должны работать после каждого этапа.
- Юнит-тесты (Vitest): easing, spring, simplify, lottie keyframe reduction, SVG-парсер на 5–10 тестовых файлах из `fixtures/`.
- Комментарии только там, где неочевидно. Никаких заглушек и псевдокода.
- Коммиты небольшие, сообщения по Conventional Commits.
- Язык: общение и README на русском, код и названия сущностей на английском.

## Критичные факты (не забывай)
- Lottie НЕ хранит настоящее 3D. Экспорт = native (трансформы плоских слоёв) → псевдо-3D → bake (проекция граней в 2D shape-слои). Определяй режим автоматически и сообщай пользователю.
- MP4 не поддерживает альфу: для прозрачного фона предлагай WebM VP9 / PNG-sequence, явно сообщай в UI.
- MP4 рендерится покадрово и детерминированно (WebCodecs + mp4-muxer), не realtime-записью.
- Только функции Lottie, поддерживаемые lottie-ios, lottie-android, lottie-web (без expressions и 3D-слоёв AE).
