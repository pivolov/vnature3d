# Logo/Icon 3D Animator

Браузерный редактор для импорта логотипов и иконок, 3D-экструзии, анимации и экспорта для мобильных приложений. На этапе 1 доступен редактор SVG и 3D-превью.

## Запуск

Требуется Node.js 24.15 или новее в ветке 24.x и браузер с WebGL 2. Все файлы обрабатываются в браузере.

```sh
npm ci
npm run dev
```

Откройте адрес, указанный Vite. Проверки проекта:

```sh
npm run build
npm test
npm run lint
```

## Как проверить редактор

1. Откройте пример «Орбита». В списке должны быть два слоя, в центре кольца видно отверстие.
2. Выберите слой, измените глубину, размер и число сегментов фаски. Подтвердите число клавишей Enter или уходом из поля.
3. Смените материал и свет, выберите другой ракурс и ортографическую проекцию. Перетаскивание мышью вращает камеру, колесо меняет масштаб. Включите гизмо, чтобы переместить выбранный слой.
4. Спрячьте слой и проверьте кнопки Undo/Redo или Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z вне полей ввода.
5. Откройте новый проект и перетащите `fixtures/evenodd.svg` во вьюпорт. Для `fixtures/malformed.svg` появится сообщение, текущая модель сохранится.

## Границы этапа 1

- SVG до 1 МБ. Градиенты отображаются первым цветовым стопом. Текст и обводки нужно перевести в контуры в исходном редакторе. SVG-маски, обрезка по границам viewBox и фильтры пока не воспроизводятся.
- История редактирования хранится в текущей вкладке. Растровый импорт, сохранение проекта, таймлайн и экспорт запланированы на следующие этапы.
