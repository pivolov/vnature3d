# VD3D — запуск через Live Server

1. Скачай ZIP этой ветки на GitHub и распакуй его в новую папку.
2. В VS Code выбери **File → Open Folder** и открой распакованную папку `vnature3d-live-server`.
3. Если расширение **Live Server** ещё не установлено, открой **Extensions**, найди **Live Server** от **Ritwick Dey** и нажми **Install**.
4. В списке файлов слева нажми правой кнопкой на `index.html` и выбери **Open with Live Server**.

Для проверки открой **«Пресеты» → «Цикл» → «Оборот 360°»**, нажми **«Применить»**, затем **▶** на таймлайне. Пресеты становятся редактируемыми ключами.

Кнопка **«Импорт»** принимает SVG до 16 МБ и PNG/JPG до 20 МБ. Кнопка **«Скачать .l3d»** сохраняет весь проект с анимацией. **«Открыть»** восстанавливает сохранённый файл. Автосохранение привязано к браузеру и адресу Live Server.

Готовая сборка включает этапы 3 и 4. Для просмотра 3D нужен браузер с WebGL 2.
