# VS3D v3 — запуск через Live Server

1. Скачай архив **VS3D v3.zip** и распакуй его.
2. В VS Code выбери **File → Open Folder** и открой распакованную папку `VS3D v3`.
3. При необходимости установи **Live Server** от **Ritwick Dey** в разделе **Extensions**.
4. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

В режиме **Просмотр** открывается сцена без панелей. Во вкладке **Пресеты** наведение показывает движение, а **Применить** добавляет ключи в таймлайн. **Экспорт** предлагает MP4, WebM с прозрачностью, один PNG или последовательность PNG в ZIP. MP4 использует выбранный цвет фона.

Для 3D нужен браузер с WebGL 2. Поддержка кодеков и максимальное разрешение зависят от браузера и видеокарты.
