# VS3D v5 — запуск через Live Server

1. Скачай **VS3D v5.zip** и распакуй архив.
2. В VS Code выбери **File → Open Folder** и открой папку `VS3D v5`.
3. При необходимости установи **Live Server** от **Ritwick Dey** в разделе **Extensions**.
4. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

## Экспорт

- **Экспорт → Lottie → Построить Lottie** выбирает режим автоматически. Сравни Lottie с 3D, проверь размер и скачай JSON или .lottie.
- Вкладка **Видео и PNG** сохраняет MP4, WebM, PNG ZIP и одиночный PNG. Для прозрачности используй PNG или WebM с альфой.
- Файлы .l3d открываются кнопкой **Открыть**. Для сохранения используй **Скачать .l3d**.

Векторный режим работает с фронтальными плоскими сценами. Запекание сложного объёма увеличивает размер файла и приближённо передаёт материалы. Проверь результат в плеере целевого приложения.
