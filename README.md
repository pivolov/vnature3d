# Logo Studio — запуск через Live Server

1. Скачай ZIP этой ветки на GitHub и распакуй его в новую папку.
2. В VS Code выбери **File → Open Folder** и открой распакованную папку `vnature3d-live-server`.
3. Если расширение **Live Server** ещё не установлено, открой **Extensions**, найди **Live Server** от **Ritwick Dey** и нажми **Install**.
4. В списке файлов слева нажми правой кнопкой на `index.html` и выбери **Open with Live Server**.

В редакторе выбери пример **«Петля»** для проверки обновлённой фаски. Кнопка **«Импорт»** открывает SVG, PNG и JPG. Для PNG и JPG сначала откроется предпросмотр контуров. Примитивы, текст и операции с контурами доступны слева.

Эта папка содержит готовую сборку этапа 2. Для 3D нужен браузер с WebGL 2.
