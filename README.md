# VD3D

Браузерный редактор для превращения SVG, PNG и JPG в 3D-фигуры. Поддерживает экструзию, векторизацию, рельеф, редактирование слоёв, анимацию и экспорт видео и кадров.

## Запуск без команд

[Скачать сборку для VS Code и Live Server](https://github.com/pivolov/vnature3d/releases/tag/vs3d-v3). Распакуйте ZIP, откройте папку в VS Code и выберите **Open with Live Server** в меню файла `index.html`. Для 3D нужен браузер с WebGL 2.

## Запуск из исходников

Требуется Node.js 24.15 или новее в ветке 24.x.

```sh
npm ci
npm run dev
```

Проверки проекта:

```sh
npm run build
npm test
npm run lint
```

## Как проверить редактор

1. Откройте «Петлю», выберите глянцевый материал и переключитесь между ракурсами «Спереди» и «3/4». Меняйте глубину, фаску и число её сегментов в инспекторе.
2. Откройте PNG с прозрачностью или JPG на сплошном фоне через кнопку «Импорт». Для JPG выберите цвет фона, затем настройте порог. Проверьте контуры перед экструзией или переключитесь на «По цветам» и «Рельеф».
3. Через «Добавить фигуру» создайте примитив или текст. Чтобы выполнить булеву операцию, выделите первый слой и выберите второй в панели «Операции с контурами».
4. Создайте группу из выбранного слоя. Перетащите слой за рукоятку на группу или перед другим слоем. Для вставки перед группой при перетаскивании удерживайте Shift. Проверьте блокировку, видимость и отмену изменений.

## Анимация и сохранение

1. Выберите слой, внизу выберите свойство и нажмите кнопку с плюсом. На линейке установите время второго ключа и измените его значение. Перетаскивайте ромбы для изменения времени. Автоключ записывает изменения инспектора на текущем кадре.
2. Выберите интерполяцию во вкладке «Ключи». Во вкладке «Кривые» перемещайте ручки Безье. Во вкладке «Сцена» доступны длина, FPS, зацикливание и каскад. Кнопка камеры во вьюпорте переключает таймлайн на дорожки камеры.
3. Во вкладке «Пресеты» наведите указатель на движение, чтобы увидеть предпросмотр. Применение создаёт обычные ключи. «Шаблоны» добавляют комбинации движения, света и материала.
4. **Скачать .l3d** сохраняет модель, материалы и анимацию. Кнопка **Открыть** загружает такой файл. На том же адресе Live Server проект восстанавливается автоматически в том же браузере.

Клавиши: пробел — воспроизведение или пауза, J/K/L — назад, пауза и вперёд, стрелки — по кадру, I — добавить ключ, Delete — удалить, Ctrl/Cmd+C/V — копировать и вставить ключ.

## Экспорт

1. **Экспорт** открывает выбор MP4 (H.264), WebM (VP9), PNG ZIP или одного кадра PNG. Выберите разрешение, пропорции и FPS. Одиночный PNG берётся с текущей позиции таймлайна.
2. Для прозрачного фона используйте WebM или PNG. MP4 компонуется поверх выбранного цвета. Для модели без движения также можно экспортировать одиночный PNG.
3. Для видео и последовательностей доступны сглаживание ×2 и накопление сэмплов движения. Видео по возможности кодируется через WebCodecs с фиксированными временными метками. При переходе на MediaRecorder редактор показывает, что запись идёт в реальном времени.
4. Для длинного файла включите «Записать сразу на диск», если браузер предлагает эту функцию. Буфер скачивания ограничен 256 МБ. Максимальное разрешение и кодеки зависят от браузера и видеокарты.

## Ограничения

- Векторизация использует рабочее изображение до 512 px по длинной стороне. Режим «Рельеф» создаёт поверхность по яркости, без объёмной подложки.
- Булевы операции работают с плоскими контурами в XY и учитывают положение и поворот по Z.
- SVG до 16 МБ и до 24 000 точек после разбора. Градиенты аппроксимируются первым цветовым стопом. SVG-текст и обводки нужно перевести в кривые до импорта. Маски, фильтры и обрезка по viewBox пока пропускаются.
- История отмены действует в текущей вкладке. Проект и его ключи сохраняются в IndexedDB и в переносимом файле .l3d. Экспорт Lottie запланирован на этап 6.
